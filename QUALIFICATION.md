# Public synthetic SVG workspace receiver

This repository is a public synthetic conformance receiver for the FS.GG SVG workspace roadmap. It contains generated public-source product and lifecycle material only. It is not a product release and contains no private receiver history, user data, credentials, captured traffic, test logs, or package archives.

The initial tree was generated by the native workspace wizard with the complete Fable game bundle and explicit Typed SDD lifecycle. Exact source identities and the reproducible invocation are recorded in `.fsgg/qualification-source.json`; package bytes used during generation are not stored here. Upstream license and third-party notice files from the generated workspace remain part of this tree.
